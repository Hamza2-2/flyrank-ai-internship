# Unassigned curriculum templates

These eight notebooks came with the starter repository but were not assignment cards in the user's attachment. They were relocated byte-for-byte, with original SHA-256 receipts in `relocation_receipt.json`. The inherited GitHub personalization workflow subsequently changed only the Colab badge repository target to Hamza's copy; current hashes are recorded separately. Scientific cells and the unexecuted status are unchanged. They are resources for future tasks.

They were moved out of the active `work/notebooks/` submission area because the inherited final-submission CI check treats their boilerplate as filled deliverables once a paper URL is present. Move a template back to its original path when starting that assignment, fill it, execute it, and commit genuine outputs. No placeholder outputs were added.
